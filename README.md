# R Data Analysis Project

This repository contains data analysis performed using R to evaluate weekly engagement metrics for a retail campaign dataset.

## 📊 Project Overview
The objective of this project is to clean, analyze, and extract insights from structured campaign data using R.

## 🧠 Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis
- Statistical Summary
- Data Manipulation with dplyr

## 🛠 Tools & Technologies
- R Programming
- dplyr
- CSV datasets

## 🎯 Purpose
This project is part of my learning journey in data analytics and bioinformatics as a PharmD student, focusing on building practical data analysis skills for healthcare and research applications.
